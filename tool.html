🪄 一鍵同步淡江課表

這個小工具會在 TKU iLife API 頁面本身執行同源 fetch，直接取得 /api/stu/course 的課表 JSON。若該頁是由「淡江課表」開啟，會優先用 postMessage 把資料送回 PWA；若手機瀏覽器沒有保留 opener，則使用接收頁面的備援方式。不會讀取或保存密碼、Cookie 或 Token。

1
先安裝一次書籤
桌面瀏覽器可以把下面的按鈕拖到書籤列。Android Chrome 請按「複製程式碼」，建立一個普通書籤，再把書籤網址替換成這段程式碼。
抓取淡江課表
2
之後每次同步
從課表 PWA 按「同步」→ 完成淡江登入 → 在 API 頁面按「抓取淡江課表」書籤；不需要全選或複製 JSON。
3
自動回到課表
工具會直接把取得的 JSON 傳回原本的課表 PWA；若手機瀏覽器沒有保留 opener，會自動跳到接收頁面完成匯入。

手機／電腦設定方式

  1. 點「複製一鍵工具程式碼」。
  2. 在 Chrome 建立書籤，例如「抓取淡江課表」。
  3. 編輯書籤，把網址欄替換成剛複製的程式碼。
  4. 之後進入 TKU iLife API 並完成登入，直接點這個書籤即可同步。
注意：這個工具必須在真正顯示 TKU JSON 的頁面執行。如果頁面只顯示錯誤、登入頁或其他文字，工具會提示你先完成登入。
