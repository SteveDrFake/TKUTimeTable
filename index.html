課表資料

這個版本先專注在穩定的 GitHub Pages 前端。你可以貼上 TKU iLife API 的 JSON，網站會在本機解析與保存。GitHub Pages 本身不能執行後端，也不能直接繞過 TKU API 的 CORS。

從淡江 iLife API 取得課表

不經過 GitHub → TKU 的 CORS。 會在淡江課表頁面本身讀取資料，再送回本網站。
尚未接收淡江課表資料。

第一次使用：先複製書籤並建立瀏覽器書籤；之後按「開啟淡江 iLife API」，完成登入，等畫面出現真正的 JSON 陣列，再點「抓取 TKU JSON」書籤。

📲 手機分享同步

一次設定，之後用手機分享回來。
把本網站安裝到主畫面後，若你的瀏覽器支援 PWA 分享目標，可以在 TKU iLife API 頁面分享 JSON 文字或 .json 檔案給「淡江課表」，網站會自動匯入。
