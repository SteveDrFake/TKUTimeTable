🪄 一鍵抓取淡江課表

這個小工具只在你已經開啟的 TKU iLife API 頁面上讀取畫面中的 JSON。若該頁是由「淡江課表」開啟，會直接用 postMessage 把資料送回 PWA；不需要把 JSON 放進網址。不會讀取或保存密碼、Cookie 或 Token。

1
先安裝一次書籤
桌面瀏覽器可以把下面的按鈕拖到書籤列。手機瀏覽器請按「複製程式碼」，再建立一個普通書籤，把網址改成這段程式碼。
抓取淡江課表
2
之後每次同步
從課表 PWA 按「開啟淡江 iLife API」→ 完成登入 → 等畫面出現 JSON → 按「抓取淡江課表」書籤。
3
自動回到課表
工具會先直接 postMessage 回原本開啟 TKU 頁面的淡江課表，並等待 PWA 回傳確認；若手機瀏覽器沒有保留 opener，會自動退回接收頁面的備援方式。

手機／電腦設定方式

  1. 點「複製一鍵工具程式碼」。
  2. 在瀏覽器建立一個新書籤，例如命名「抓取淡江課表」。
  3. 編輯該書籤，把網址欄完整替換成剛複製的程式碼。
  4. 之後不用再複製 JSON；進入 TKU API 頁面直接點這個書籤即可。
注意：這個工具必須在真正顯示 TKU JSON 的頁面執行。如果頁面只顯示錯誤、登入頁或其他文字，工具會提示你先完成登入。
